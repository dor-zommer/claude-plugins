# hamakom-event-verification — אימות אירועי שטח

מקבל דיווח מרובה-אירועים (למשל "23 תקיפות ב-24 שעות") ומחזיר דוח אימות: מה אומת, ממי, מה נשאר בגדר דיווח יחיד, ומה התגלה בדרך. **הסקיל מסתיים בדוח האימות** — כתיבת הכתבה היא שלב נפרד (hamakom-source-to-item).

## חוק ברזל: איפה ה-osint-db האמיתי

**ערוץ ראשי — MCP:** אם כלי `mcp__osint-db__*` זמינים (query_db, list_tables) — השתמש בהם.

**ערוץ גיבוי — SSH ל-VM:** אם ה-MCP לא מחובר, המסד החי רץ על VM בגוגל קלאוד. **אל תשתמש בקובצי osint.db על המק** — הם עותקים ישנים/ריקים.

- VM: `telegram-bot`, zone `me-west1-a`, פרויקט `gen-lang-client-0999174762` (gcloud מוגדר על המק)
- נתיב: `/home/dorzommer/osint.db` (עותק נוסף: `/var/www/osnat/osint.db`)
- גישה:
```bash
gcloud compute ssh telegram-bot --zone=me-west1-a --command="sqlite3 -separator ' ||| ' /home/dorzommer/osint.db 'SELECT ...'"
```

### טבלאות מפתח
- `news_headlines` — ~21 אלף כותרות, 31+ מקורות, מתעדכן שוטף. עמודות: outlet, headline, headline_he, url, pub_iso, category, scraped_at. מקורות: וופא, אל-ג'זירה (ער'+אנג'), אל-קודס, שהאב, פלסטין אונליין, הארץ, Ynet, מעריב, וואלה, N12, ערוץ 7, סרוגים, כיפה, JDN, זמן ישראל, BBC, Guardian, NYT, WaPo, Le Monde, FT ועוד.
- `police_announcements` — הודעות דוברות משטרת ישראל, ערוץ הטלגרם הרשמי (Israel_Police_100). עמודות: pub_date, text, url. **מקור ראשוני מדרגה ראשונה** — כולל פרטי עצורים וחקירות.

### שאילתה טיפוסית
```sql
SELECT outlet, headline, url FROM news_headlines
WHERE scraped_at >= 'YYYY-MM-DD'
  AND (headline LIKE '%מתנחל%' OR headline LIKE '%settler%' OR headline LIKE '%<שם מקום>%')
ORDER BY scraped_at DESC LIMIT 60;
```
חפש שמות מקומות בשלוש שפות (סוריף / Surif / صوريف).

## כללי מקורות (הסטנדרט של דור)

- **כשר:** וופא, מקורות מקומיים פלסטיניים, אל-קודס, אל-ג'זירה, כל תקשורת ישראלית ובינלאומית, הודעות רשמיות (משטרה/צה"ל), ארגונים (בצלם, יש דין, OCHA, HRW), גופי רש"פ (בייחוס).
- **פסול כאימות עצמאי:** מקורות חמאסיים — שיהאב, "מרכז המידע הפלסטיני"/Palinfo/PIC, פלסטין אונליין (Felesteen). מותר לציין שדיווחו; אסור לבסס עליהם.
- **שרשרת ממוחזרת אינה אימות:** Palestine Uncensored, PLF Pakistan ודומיהם משכפלים את אותו סבב דיווח — מקור אחד, לא שניים.

## שיטת העבודה

1. **פירוק לרשימה.** כל אירוע בנפרד: מקום, זמן, מה קרה, נפגעים. שמות מקומות בשלוש שפות.
2. **osint-db קודם.** news_headlines + police_announcements בטווח התאריכים. הודעת משטרה = אימות רשמי.
3. **רשת במקביל.** WebSearch פר-אירוע: WAFA English (english.wafa.ps), Times of Israel, אל-ג'זירה, MEE, Drop Site, בצלם, OCHA. עמוד ענק מ-WebFetch — grep על הקובץ שנשמר.
4. **מלכודת התאריכים.** אירוע ישן ממוחזר לחלון זמן חדש (באר שנתפסה 10 ימים קודם) — בדוק תאריך פרסום מקורי של כל אירוע. בדוק ימי שבוע מול תאריכים.
5. **חפש את הגרסה הרשמית הישראלית.** הודעות דוברות המשטרה ודובר צה"ל לעיתים מוסרות פרט שהדיווח הפלסטיני לא ידע (זהות עצור, חקירה שנפתחה) — לרוב זה הממצא החזק ביותר.
6. **מספרים מצרפיים — רק עם הגדרה.** OCHA (תקיפות עם נפגעים/נזק בלבד) ≠ ספירות פלסטיניות רחבות (כולל השתלטויות/הצתות) ≠ ספירות "צבא+מתנחלים". אסור לערבב, אסור להציג ספירה רחבה כספירת אלימות מתנחלים.
