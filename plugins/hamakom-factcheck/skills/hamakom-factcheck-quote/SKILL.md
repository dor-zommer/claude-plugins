# hamakom-factcheck-quote - אימות ציטוטים וייחוס

סקיל לאימות אמירות עבור דסק "המקום הכי חם בגיהנום": האם נאמר, מי אמר, מתי, ובאיזה הקשר. התוצר הוא דוח דסק בעברית עם קישור למקור הראשוני של האמירה.

## עקרונות יסוד

1. **המקור הראשוני הוא האמירה עצמה, לא הדיווח עליה.** וידאו/אודיו של האירוע, תמליל רשמי, פרוטוקול ועדה, או ההקלטה המקורית - לא הציוץ ש"ציטט". בלי מקור ראשוני: "לא אומת".
2. **הקטיעה היא ההטעיה השכיחה.** רוב הציטוטים השגויים אינם בדויים אלא אמיתיים-וחתוכים. תמיד אתר את המשפט שלפני ואחרי - ההקשר משנה את המשמעות.
3. **ייחוס ≠ אמירה.** "מצוטט בשם X" אינו ראיה ש-X אמר. אתר את ההופעה הראשונה של הייחוס ובדוק אם יש מקור או רק גלגול.
4. **תרגום הוא ראיה חלשה.** אם האמירה תורגמה (מעברית/ערבית/אנגלית) - אתר את הנוסח בשפת המקור; ניואנס תרגום הופך אמירה.
5. **כשאי-אפשר לקבוע - הערך כיוון והסתברות.** ציין לאן נוטות הראיות וברמת ביטחון, ומה הראיה שתכריע. אל תציג הערכה כעובדה.

## שלב 1 - חילוץ האמירה והייחוס

- **הנוסח המדויק** של הציטוט כפי שמסתובב (במירכאות, מילה במילה).
- **למי מיוחס** ובאיזו הזדמנות נטענת (נאום, ריאיון, ישיבה, פוסט).
- **מי מפיץ** את הייחוס ומה המקור שהוא נותן (אם בכלל).
- **תאריך/אירוע** נטענים.

## שלב 2 - איתור המקור הראשוני של האמירה

לפי סוג ההזדמנות:

| סוג אמירה | מקור ראשוני |
|---|---|
| דברים בוועדה | פרוטוקול הוועדה. הטקסט המלא ב-**osint-db** (ראה "חיפוש בפרוטוקולי הכנסת" למטה); מועד הישיבה ב-knesset_committee_sessions |
| דברים במליאה | "דברי הכנסת" של הישיבה. הטקסט המלא ב-**osint-db**, באותו מבנה |
| ריאיון בתקשורת | הקלטת/תמליל התוכנית המקורית (לא הציטוט המשני) |
| נאום/הצהרה רשמית | אתר הגוף (משרד, מפלגה), ערוץ הווידאו הרשמי |
| פוסט ברשת | הפוסט המקורי עצמו (ראה hamakom-factcheck לקליטה ב-Chrome) |
| הקלטה שדלפה | המקור שפרסם ראשון + אימות אותנטיות בנפרד |

חפש את **הנוסח המדויק במירכאות** במנועי חיפוש ובכמה שפות. אם האמירה בווידאו - אתר את הקליפ המלא ונווט לרגע האמירה (Pause + סרגל התקדמות; zoom לכתוביות אם יש).

### חיפוש בפרוטוקולי הכנסת (osint-db)

הטקסט המלא של פרוטוקולי הוועדות ושל דברי הכנסת (המליאה) נמצא ב-`knesset_document_texts`, ומחובר למסמך דרך `knesset_documents` (עמודת `sha256`). `knesset_session_documents` מחזיקה רק קישור לקובץ, לא טקסט.

**תמיד לצמצם קודם לוועדה ולתקופה, ורק אז לחפש בטקסט.** חיפוש בכל הפרוטוקולים בבת אחת חורג ממגבלת הזמן של השרת. ועדה אחת בשנה אחת עוברת בכמה שניות.

ועדה (שם הוועדה והתאריך נמצאים ב-`document_name`, למשל "פרוטוקול מספר 68, ועדת הבריאות, 27/06/2023"):
```sql
WITH docs AS MATERIALIZED (
  SELECT doc_id, document_name, file_url, sha256 FROM knesset_documents
  WHERE group_type_desc = 'פרוטוקול ועדה'
    AND document_name LIKE '%ועדת הבריאות%'
    AND document_name LIKE '%/2023')
SELECT d.document_name, d.file_url,
       substr(t.text, greatest(strpos(t.text, 'קופות החולים') - 300, 1), 800) AS context
FROM docs d JOIN knesset_document_texts t ON t.sha256 = d.sha256
WHERE strpos(t.text, 'קופות החולים') > 0
ORDER BY d.doc_id DESC LIMIT 10;
```

מליאה (למסמך אין שם; התאריך בא מ-`knesset_plenum_sessions`):
```sql
WITH docs AS MATERIALIZED (
  SELECT d.doc_id, d.file_url, d.sha256, s.start_date
  FROM knesset_documents d JOIN knesset_plenum_sessions s ON s.id = d.parent_id
  WHERE d.doc_set = 'plenum' AND d.group_type_desc = 'דברי הכנסת'
    AND s.start_date >= '2025-01-01' AND s.start_date < '2025-07-01')
SELECT d.start_date, d.file_url,
       substr(t.text, greatest(strpos(t.text, 'ועדת חקירה ממלכתית') - 300, 1), 800) AS context
FROM docs d JOIN knesset_document_texts t ON t.sha256 = d.sha256
WHERE strpos(t.text, 'ועדת חקירה ממלכתית') > 0
ORDER BY d.start_date DESC LIMIT 10;
```

מחפשים קטע קצר ומובחן מהציטוט (שלוש-ארבע מילים) ולא את כולו: החיפוש מדויק לאות, ומילה אחת ששונתה בין הנוסח שמסתובב לנוסח הפרוטוקול מספיקה כדי שלא יימצא. ה-`context` נותן את מה שנאמר לפני ואחרי, ושם הדובר מופיע בטקסט לפני דבריו. הקובץ הרשמי ב-`file_url` הוא המקור לדוח.

**כיסוי (נמדד 20.11.2026):** פרוטוקולי ועדות עם טקסט מהכנסת ה-20 עד ה-25 (בכנסות 18-19 אין טקסט, ולכנסת ה-26 אין עדיין פרוטוקולי ועדות במאגר). דברי הכנסת עם טקסט מהכנסת ה-20 עד ה-26. מחוץ לזה, או כשהמקור לא רץ, תוצאה ריקה אינה "לא נאמר". לפני מסקנה כזו לבדוק שהמקור רץ:
```sql
SELECT source, max(started_at) FROM scrape_runs
WHERE status IN ('ok','warn') AND source IN ('knesset_texts', 'knesset_committee_sessions') GROUP BY 1;
```

## שלב 3 - בדיקת ההקשר המלא

- **לפני ואחרי:** מה נאמר סביב המשפט. האם המשמעות משתנה כשמחזירים את ההקשר.
- **טון וכוונה:** ציני/היפותטי/ציטוט-של-מישהו-אחר בתוך האמירה.
- **שלמות:** האם הושמטו מילים שמשנות (שלילה, תנאי, "לא").
- **ההזדמנות:** האם נאמר במועד/בפורום שנטענים.

## שלב 4 - פסיקת ייחוס

לכל ציטוט פסוק אחת מ: **נאמר כלשונו** / **נאמר אך מחוץ להקשר** / **נאמר בשינוי נוסח** / **מיוחס בטעות (אמר מישהו אחר)** / **בדוי - אין מקור** / **לא ניתן לאמת**. אם בדוי או מיוחס בטעות - נסה לאתר את המקור האמיתי של הניסוח.

## התמודדות עם תקלות

| תקלה | פתרון |
|---|---|
| חיפוש מחזיר רק ציטוטים משניים | חפש את הנוסח המדויק במירכאות + שם הדובר + מילת אירוע; סנן לתאריך מוקדם |
| הווידאו המקורי ירד | Wayback Machine דרך Chrome; חפש מירורים/העלאות חוזרות |
| תמליל הכנסת לא נפתח | הטקסט ב-osint-db (השאילתות למטה); הקישור לקובץ ב-`file_url`; או אתר הכנסת דרך navigate |
| אמירה בשפה זרה | אתר נוסח מקור; הצלב תרגום מול דובר השפה/מקור רשמי |

**אסור:** להציג תרגום כציטוט מקור, או לקבוע "בדוי" בלי שמיצית חיפוש בכמה שפות וארכיון.

## אתיקה

הבחן בין דמות ציבורית (אמירותיה הציבוריות פתוחות לבדיקה) לאדם פרטי. אל תקבע "מעולם לא אמר" אלא "לא נמצא מקור" - היעדר ראיה אינו ראיה להיעדר.

## ניהול העבודה

TaskCreate: חילוץ האמירה והייחוס, איתור המקור הראשוני, בדיקת הקשר. אם מתברר שהציטוט אמיתי אך מחוץ להקשר - אמור מיד.

## דוח הדסק - מבנה קבוע

```markdown
# מה מצאתי

## הציטוט שנבדק
[הנוסח המדויק, למי מיוחס, באיזו הזדמנות, מי מפיץ]

## המקור הראשוני
[היכן נאמר באמת + קישור (וידאו/תמליל/פרוטוקול) + תאריך.
אם osint-db: השאילתה ו-file_url. הנוסח המדויק כפי שבמקור]

## ההקשר המלא
[מה נאמר לפני ואחרי, הטון, מה הושמט. האם ההקשר משנה משמעות]

## הפסיקה
[נאמר כלשונו / מחוץ להקשר / בשינוי נוסח / מיוחס בטעות / בדוי / לא אומת.
אם לא ניתן לקבוע: כיוון הראיות + רמת ביטחון + הראיה החסרה]

**שורה תחתונה לדסק:** [משפט-שניים: אפשר לצטט כפי שהוא / רק עם ההקשר /
לא לצטט - והניסוח המומלץ]

Sources: [כל הקישורים + שאילתות osint-db]
```

כתוב בעברית, בלי אימוג'ים, חד וקצר.
