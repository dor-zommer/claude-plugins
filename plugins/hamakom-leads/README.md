# ha-makom-newsroom

פלאגאין מערכת חדשות עבור "המקום הכי חם בגיהנום" — מכין את העורך הראשי לישיבת מערכת.

## חמשת הסקילים

1. **`/newsroom-pipeline`** — מארג: מריץ את 4 הסקילים האחרים ברצף
2. **`/osint-scout`** — סריקת אקטואליה (24-48 שעות, עברית בלבד)
3. **`/gov-data-scout`** — לידים מבניים ממסדי מידע ממשלתיים
4. **`/news-briefing`** — סקירת חדשות יומית לקונטקסט
5. **`/desk-editor`** — דסק עיתונאי: טריאז' + פיץ' עומק

## כללי הברזל החוצים

- **שפה:** עברית בלבד. חריגים: WAFA / אל-ג'זירה (ערבית), NYT / WaPo / Guardian / BBC / Reuters / AP / WSJ / FT / The New Yorker / ProPublica (אנגלית).
- **חלון זמן:** 24-48 שעות. סקירת חדשות יומית: 12-24.
- **אימות תאריך:** `web_fetch` חובה על כל כתבה.
- **שמירה על מסגור:** "30 משתתפים בכל הדלקה" לא להפוך ל-"30 משתתפים בלבד".
- **הצלבה:** מספר/ציטוט בכותרת = 2 מקורות, או תיוג "מקור יחיד".
