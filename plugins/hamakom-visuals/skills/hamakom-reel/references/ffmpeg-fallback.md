### שלב 1 - היכרות עם הפוטג'
לכל קובץ וידאו: `ffprobe` (רזולוציה, אורך, האם יש אודיו), ואז רשת פריימים להבנת התוכן:
```bash
ffmpeg -y -v error -i IN.mp4 -vf "fps=1/10,scale=480:-2,tile=3x3" grid.png
```
**להסתכל על הרשתות** (Read) ולכתוב לעצמך מה רואים בכל קליפ ובאילו חלונות זמן יש
אקשן. מקליפים ארוכים גוזרים רק את חלונות הפעולה - קליפ אבטחה של 90 שניות שבו
האקשן בשניות 8–35 נכנס לריל רק בחלון הזה. תמונות סטילס: 3–4 שניות עם זום עדין (zoompan).

### שלב 2 - חילוץ משפטי מפתח
מהכתבה בוחרים 6–9 משפטים: **הפתיח הוא תמיד כותרת הכתבה (h1) מילה במילה**
(עיקרון 1b), אחריו משפטי עובדה שמתאימים לוויז'ואל שיש, ומשפט נפגעים/תוצאה.
סדר הופעה = קשת נרטיבית: כותרת → השתלשלות → שיא → תוצאה. משפט בלי ויז'ואל
מתאים - עדיף לוותר עליו.
דברים שדור הוריד בעבר: משפטי פרשנות/השוואה גרנדיוזיים ("מחזה שמזכיר את...").
עדיף עובדות קשות.

**סביל → פעיל:** ציטוט מילה-במילה נשאר ברירת המחדל, **אבל משפט סביל בלי עושה
מומר לפעיל שממנה את העושה**: "מושחת צינור המים" → "מתנחלים משחיתים את צינור
המים" (או הורסים/פוגעים/משביתים). האחריות על מי שביצע גוברת על מילה-במילה.

### שלב 3 - תכנון טיימליין
45–120 שניות סך הכל, כולל סגיר. כל מקטע 5–20 שניות (הוק קצר, תיעוד מתמשך יכול
להיות ארוך יותר). לכתוב טבלה: מקטע / מקור+חלון / משפט / האם אודיו מקור נשמע.

### שלב 4 - כרטיסי טקסט + אוברליי (נתיב ffmpeg - גיבוי; ב-HyperFrames ר' "מנוע הרכבה")
`scripts/make_cards.py` - לערוך את רשימת הכרטיסים בתחתית הקובץ ולהריץ.
`scripts/make_overlay.py` - בונה פעם אחת את overlay.png (גרדיאנט דיו + לוגו
ריבועי + URL + פס-חתימה) לכל המקטעים.
**רינדור עברית: אין libraqm במק של דור** (`features.check('raqm')` = False) - בכל סקריפטי הטקסט משתמשים ב-`bidi.algorithm.get_display` ומסירים
`direction='rtl'`/`'ltr'`, אחרת ValueError. עברית עם גרש - גרש עברי ׳ (U+05F3),
לא אפוסטרוף לטיני. לבדוק ויזואלית כרטיס אחד לפחות לפני ההמשך.

### שלב 5 - רינדור מקטעים (נתיב ffmpeg - גיבוי; וידאו בלבד, בלי אודיו!)
`scripts/normalize_segment.sh IN OUT SS T CARD` - מנרמל ל-1080x1920: רקע מטושטש
(scale קטן → boxblur → scale חזרה: מהיר פי כמה מ-gblur על full-res), פוטג' ממורכז,
overlay.png (גרדיאנט + לוגו + URL + פס), כרטיס בשליש התחתון (margin 240px),
fps=30 כפוי, `-an`.
סגיר: קודם כל `closer_v3.mp4` מהתיקייה הקבועה - כמות שהוא. רק אם צריך CTA אחר:
`scripts/make_closer_assets.py` (fA..fD.png + sting.wav) ואז `scripts/make_closer.sh`.
**מגבלת זמן קריטית:** כל פקודת bash מוגבלת ל-45 שניות, ותהליכי רקע נהרגים בסוף
הקריאה (nohup/setsid לא עוזרים). לכן מקטע אחד או שניים לכל קריאת bash. קליפ מקור
ארוך מ-40 שניות - לפצל קודם עם `-c copy -f segment` ולנרמל כל חלק בנפרד.

### שלב 6 - סינק: חיבור וידאו ובניית אודיו בנפרד (נתיב ffmpeg - גיבוי; ב-HyperFrames האודיו נשאר על הקליפ)
זה הלקח הכי חשוב מהפעם הראשונה (היה דריפט והסאונד זלג בין קליפים):
1. קונקט וידאו: `ffmpeg -f concat -safe 0 -i list.txt -c copy body.mp4` - מקטעים
   זהי-קידוד מתחברים בלי דריפט כשאין אודיו.
2. ספירת פריימים אמיתית לכל מקטע:
   `ffprobe -count_frames -show_entries stream=nb_read_frames`
   (יוצא לפעמים פריים אחד פחות מהמוזמן - לכן סופרים, לא מניחים).
3. אופסט של כל מקטע = סכום הפריימים שלפניו ÷ 30. ב-ms עבור adelay.
4. חילוץ אודיו מקור רק למקטעים שמשמיעים: loudnorm (I=-16:TP=-1.5:LRA=11),
   `atrim`+`apad` לאורך המקטע המדויק.
5. מיקס: כל קטע `adelay=OFFSET|OFFSET`, amix לטראק אחד, sidechaincompress של
   המוזיקה מולו (threshold=0.02:ratio=6:attack=80:release=600), amix סופי,
   `alimiter=limit=0.85:level=false` (לא ברירת המחדל - level=true מגביר!) ואחריו
   `apad=whole_dur=TOTAL,atrim=0:TOTAL`. חובה `aformat` לפני sidechaincompress
   (אחרת שגיאת פורמטים). מלכודות המיקס המלאות - `references/sync-method.md`.
6. mux: `-map 0:v -map "[a]" -c:v copy`.
פירוט מלא עם פקודות מוכנות: `references/sync-method.md`.

### שלב 8 - וריפיקציה (לא לדלג)
- רשת פריימים מהקובץ הסופי - מקטע מכל סוג + הסגיר - ולהסתכל בעיניים.
- `ffprobe` שאורך האודיו == אורך הווידאו (עד 0.05 שנ').
- volumedetect: שיא סביב -1 עד -3dB.
- פריים אחד בגודל מלא לבדיקת קריאות הטקסט.
שמירה: outputs בשם עברי ברור, `present_files`, ולציין שכדאי האזנה אחת למיקס.
