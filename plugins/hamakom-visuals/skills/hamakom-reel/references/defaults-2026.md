## אנימציות - חובה (הנחיית דור, 26.07.2026)

**אין ריל בלי תנועה.** כל מקטע חייב לפחות שכבת אנימציה אחת; כרטיס טקסט שנכנס
כמו חותמת וסטיל שלא זז - פסולים.

| שכבה | האנימציה | ffmpeg |
|---|---|---|
| **רקע (סטיל)** | zoompan רציף, 6-10% לאורך המקטע. לסירוגין zoom-in / zoom-out בין מקטעים כדי שלא ירגיש מכני | `zoompan=z='min(zoom+0.0006,1.10)':d=<frames>:s=1080x1920:fps=30` |
| **רקע (וידאו)** | לא נוגעים בפוטג' - הוא כבר נע | - |
| **כרטיס טקסט** | **fade+rise**: עולה 40px ונכנס ב-0.5 שנ' בקלות `easeOutCubic` | `overlay=y='H-h-240+40*max(0,1-t/0.5)':enable=...` + `format=rgba,fade=t=in:st=0:d=0.5:alpha=1` |
| **מספר-מחץ** | **count-up**: המספר נספר מ-0 ליעד ב-0.8 שנ' | רצף PNG (`make_cards`) או `drawtext` עם `%{eif}` |
| **גרף** | **הבר גדל משמאל לימין** ב-0.9 שנ' | לרנדר את ה-HTML כרצף פריימים (ראה למטה) |
| **מעברים** | crossfade 0.35 שנ' בין מקטעים - לא cut יבש | `xfade=transition=fade:duration=0.35:offset=<t>` |
| **סגיר** | `closer_v3.mp4` כבר מונפש - לא נוגעים | - |

**גרפים מונפשים:** הגרף נבנה כ-HTML (אותה שפת עיצוב של האינפוגרפיקות בכתבה),
עם `@keyframes` על רוחב הבר ו-count-up על המספר, ומרונדר לרצף פריימים:

```bash
# רצף פריימים מ-HTML מונפש (Chrome headless, 30fps)
for i in $(seq 0 44); do
  "$CHROME" --headless=new --disable-gpu --hide-scrollbars --window-size=1080,1920 \
    --virtual-time-budget=$((i*33)) --screenshot="frames/f$(printf %03d $i).png" "file://$G"
done
ffmpeg -y -framerate 30 -i "frames/f%03d.png" -c:v libx264 -pix_fmt yuv420p graph.mp4
```

**מלכודת:** `--virtual-time-budget` הוא הדרך היחידה לתפוס פריים באמצע אנימציית CSS
ב-headless; בלעדיו כל הצילומים יוצאים בפריים הסופי.

## כתוביות קריוקי - מילים שנצבעות בקצב קריאה (נוסף 02.08.2026)

סגנון חלופי לכרטיס הסטטי: המשפט מוצג בלבן והמילים נצבעות **sc-terra #E8906F**
במצטבר, מילה-מילה, בקצב קריאה מוסכם. מנוע: `scripts/make_karaoke.py` - רצף PNG
ב-PIL+bidi (אותו מנוע של הכרטיסים) שנארז ל-MOV שקוף (qtrle) ומולבש כמו כרטיס.
**לא ASS/libass** - ה-ffmpeg של דור בלי libass, וקריוקי RTL ב-libass שביר.

**קצב הקריאה המוסכם** (עוגן: Netflix Hebrew TTSG, תקרה 17 CPS למבוגרים; אנחנו
שמרנים יותר כי הטקסט על וידאו):

| פרמטר | ערך |
|--------|-----|
| קצב | **15 תווים/שנייה (CPS)** |
| מינימום למילה | 0.25 שנ' |
| lead-in לפני הצביעה | 0.4 שנ' |
| hold אחרי המילה האחרונה | ≥ 1 שנ' |
| אורך מקטע נגזר | ceil(תווים/15 + 1.6) שנ' |

**פונטים וצבעים:** המשפט Publico Headline לבן; ההדגשה sc-terra; קיקר Graphik
Medium sc-terra. חוקי ה-verbatim וה-safe zones חלים כרגיל.

**שימוש:**
```bash
python3 scripts/make_karaoke.py "הטקסט מילה במילה" <DURATION> <NAME> --size 52 [--kicker "..."]
# פלט: $REEL_WORKDIR/karaoke/NAME.mov - מחליף את input הכרטיס ב-normalize
# (בלי -loop 1! זה וידאו, לא PNG; overlay מחזיק את הפריים האחרון עד סוף המקטע)
```

מתי להשתמש: ציטוטי עדות ומשפטי מפתח שרוצים שיוחזקו לאורך מקטע ארוך; הכרטיס
הסטטי נשאר ברירת המחדל לכותרת ה-h1 ולמשפטים קצרים.

## Safe zones - חוק ברזל (נוסף 02.08.2026, אחרי שדור הוריד פוסט בגלל טקסט מוסתר)

**ה-UI של טיקטוק ואינסטגרם מכסה חלקים גדולים מהפריים. טקסט שנכנס לאזורים האלה - הפוסט פסול.**
בפוסט שדרות (02.08.2026) הכרטיסים ישבו ב-bottom margin 240px ונבלעו מאחורי הקאפשן
והכפתורים; דור הוריד את הפרסום. המספרים (מקורות: kreatli, zeely, quso 2025-2026):

| אזור | כמה ה-UI מכסה (1080×1920) | הכלל שלנו |
|------|----------------------------|------------|
| תחתית | ~484px (קאפשן, CTA, פס ניווט) | **תחתית כל טקסט ≥ 500px מהתחתית (y ≤ 1420)** |
| ימין | ~150px (לייקים, תגובות, שיתוף, פלייליסט) | אין טקסט קריטי ב-150px הימניים |
| למעלה | ~130px (סטטוס-בר, טאבים) | הלוגו ב-y≈150, לא ב-48 |
| כלל-זהב חוצה-פלטפורמות | - | כל הטקסט בתוך מלבן **900×1400 ממורכז** (x 90-990, y 260-1660, ובטיקטוק תחתית עד 1420) |

יוצא דופן יחיד: פס-החתימה הטריקולור (4px) נשאר בקצה התחתון - הוא דקורטיבי ומותר
שיוסתר. **ה-URL אינו יוצא דופן** - הוא יושב מתחת לכרטיס (y=H-485), לא בתחתית.

**QA חובה לפני מסירה:** פריים בדיקה אחד עם גריד safe-zone (או השוואה ידנית למספרים
בטבלה) - לוודא שאף שורת טקסט לא חוצה y=1420 ולא נכנסת ל-150px הימניים.
