# hamakom-distribute — קופי ותזמון

**מה הסקיל הזה כן:** ניסוח קופי פר-פלטפורמה, ותזמון טיוטות ב-Hootsuite.
**מה הוא לא:** לא מעצב ולא מרנדר. הוא יושב בפלאגין `hamakom-visuals` לצד סקילי הוויז'ואלס
(הועבר לכאן מהריפו הפרטי ב-27.10.2026), אבל לא משכפל אותם:

| צריך | הסקיל |
|---|---|
| טריגר "כתבה פורסמה" | `hamakom-publish-trigger` (ב-hamakom-visuals) |
| 3 גרפיקות בודדות | `hamakom-graphic` |
| קרוסלה | `hamakom-carousel` |
| ריל | `hamakom-reel` |

**אסור לשכפל לכאן לוגיקת עיצוב.** שינוי ויזואלי = עריכת הסקיל הרלוונטי או
`design-system/HAMAKOM-DS-2026.md`.

## 1. קופי — **לקאפשיינים בלבד**

`references/social-voice-dna.md` — ניתוח של **299 קאפשיינים אמיתיים** של @ha_makom.
**לקרוא לפני ניסוח.**

> **גבול השימוש:** ה-DNA חל על **טקסט הפוסט** ותו לא. **אסור** להשתמש בו לשקפי
> קרוסלה, לכותרות גרפיקה או לטקסט על תמונה — לאלה יש מפרטים משלהם, והכותרת
> בגרפיקה היא **h1 verbatim**.

```bash
S="$(ls -d ~/.claude/plugins/cache/hamakom-plugins/hamakom-visuals/*/skills/hamakom-distribute/scripts 2>/dev/null | sort -V | tail -1)"
S="${S:-$HOME/Developer/hamakom-claude-plugins/plugins/hamakom-visuals/skills/hamakom-distribute/scripts}"
python3 "$S/write_posts.py" <תיקיית-ההפצה>/article.json <תיקיית-ההפצה>
```
מייצר `posts.md` מוכן לכל פלטפורמה. **לא מנסחים תקציר משלנו** (דור, 2.11.2026):

| רשת | הטקסט | גרפיקה |
|---|---|---|
| פייסבוק, X | h1 מילה במילה · המשנה מילה במילה · ״כל הפרטים בכתבה של <שם>:״ + קישור קצר | מרובעת (whatsapp-1080x1080) |
| אינסטגרם | h1 · משנה · ״כל הפרטים בכתבה של <שם>, עכשיו בביו ובסטורי שלנו״ · `#המקום_הכי_חם_בגיהנום` | 4:5 (instagram-1080x1350) |
| טיקטוק | כמו אינסטגרם; כותרת הפוסט = h1 | הסטורי (ig-story-1080x1920) כפוסט תמונה |
| וואטסאפ, טלגרם | הפורמט הקבוע של `hamakom-whatsapp-item`: `*h1*`, המשנה, ״הדיווח של <שם> - עכשיו באתר >>״, קישור קצר, ופוטר (invest / whatsapp / t.me/ha_makom) | מרובעת |

דור: ״תשנה שההוק יהיה הכותרת כלשונה באתר״, ואחר כך ״יתר הטקסט בפוסטים - בבקשה את המשנה״.
הכותרת והמשנה כבר עברו עריכה; שכתוב שלהן לתקציר ״בקול הרשתות״ הוא בדיוק מה שדור החליף.
בטור דעה: ״בטור של״ ו״הטור המלא של״ (`"genre": "opinion"` ב-article.json). ה-DNA
ב-`social-voice-dna.md` נשאר מקור לטון כשדור מבקש ניסוח חופשי (ריל, פוסט מיוחד), לא ברירת מחדל.

- **קרדיט תמונה** רק לצילום, כלשונו מה-figcaption (`image_credit`). איור בינה מלאכותית
  (`"image_ai": true`) - בלי שורת ״צילום״, ובאינסטגרם מסמנים `isAiGenerated`.
- משנה ריקה ב-article.json (טיוטה) נשלפת מהאתר החי. אין משנה באתר - עוצרים.

### קישורים קצרים - `ha-makom.co.il/{fb|x|wa|tg}/<key>`

דור: ״זה לא מקוצר״. הקישור בקופי הוא הקישור הקצר של האתר, בלי https, ומאחוריו הפניה
בתוסף Redirection לכתבה עם UTM של הרשת. **לא wp.me** - הוא מוחק את ה-UTM.

```bash
python3 "$S/short_links.py" <תיקיית-ההפצה>/article.json <key>            # בדיקה: מה קיים ומה חסר
python3 "$S/short_links.py" <תיקיית-ההפצה>/article.json <key> --create   # יצירת החסרים
python3 "$S/write_posts.py" <תיקיית-ההפצה>/article.json <תיקיית-ההפצה>  # קורא את short_links.json
```
ה-`key`: מילה לטינית קצרה מהסיפור (`carlson`, `yafo`). הפניה קיימת שמפנה לכתבה אחרת
לא נדרסת - הסקריפט עוצר. ההפניות: קבוצה 1, קוד 302, `match_type: url`.

## 2. תזמון ב-Hootsuite — טיוטות בלבד

> **קרא את `references/hootsuite-guard.md` לפני כל פעולה מול Hootsuite. חוק ברזל.**

**שלב א' = תזמון בלבד, אפס פרסום.** `publish_post` **לא ב-`allowed-tools`** — חסום
מכנית. גם אם מתבקש "תפרסם" — לעצור ולהפנות את דור לפרסם בעצמו מ-Hootsuite.

**Whitelist קשיח — רק 3 הפרופילים של המקום** (workspace ארגוני `1093735`):
`140428899` ha_makom (IG) · `140428898` פייסבוק · `140428906` וואטסאפ.
החיבור חושף גם את **שקוף** ואת **העין השביעית** — **אסור מוחלט לגעת בהם.**
לפני כל `create_draft`: להריץ `get_social_profiles`, לוודא שכל ID ברשימה המותרת,
ואם לא — **לעצור ולדווח.**

```
request_media_upload → PUT (curl) → poll_media_upload → create_draft(scheduledDate=…)
→ list_drafts (אימות)
```
`create_draft` שומר טיוטה בתוך Hootsuite בלבד; היא מופיעה ביומן התכנון באפור
ו**לעולם לא מתפרסמת מעצמה**. זמנים: `get_recommended_times` עם `timezone: "Asia/Jerusalem"`.

## 3. פרסום ב-Metricool - רק בבקשה מפורשת של דור

הסקיל לא מפרסם מיוזמתו. כשדור מבקש ״תעלה דרך מטריקול״:

- **מותג:** `blogId 5684615`, אזור זמן `Asia/Jerusalem` (מ-`getBrandSettings`).
- **מדיה:** כתובת ציבורית. הגרפיקות מ-Figma מעלים קודם לספריית המדיה של האתר
  (`POST /wp/v2/media`) ומעבירים את ה-`source_url`.
- **פוסט לכל רשת**, כל אחד עם הגרפיקה שלו לפי הטבלה למעלה. אינסטגרם `type: POST`,
  ועם איור AI `isAiGenerated: true`. טיקטוק: `tiktokData.title` = h1, `privacyOption: PUBLIC_TO_EVERYONE`.
- **X:** טקסט ארוך מ-280 תווים עובר רק בחשבון Premium. לא מקצרים לבד - שולחים, ואם
  Metricool מחזיר שגיאה, מדווחים לדור.
- **עדכון פוסט מחליף לו id** (ה-uuid נשאר). ממשיכים עם ה-id שהוחזר. העדכון מחליף את כל
  הפוסט, ולכן שולחים את כל השדות. המועד לא יכול להיות בעבר - כשמעדכנים דקות לפני
  הפרסום, דוחים בכמה דקות.
- **דור עשוי לערוך בעצמו** ב-Metricool. לפני עדכון: `getScheduledPosts`, ופוסט שדור כבר
  שינה (מועד יצירה חדש, טקסט אחר) - לא דורסים, לומדים ממנו (כך נקבעה שורת ״כל הפרטים בכתבה של״).

## 4. וואטסאפ ווב (צ'אט עצמי) - טקסט קודם, תמונה אחר כך

דור: ״אתה קודם אמור לשים את הטקסט ואז רק את התמונה״. בכרום, בצ'אט של דור עם עצמו:

1. לנקות טיוטה שנשארה בשדה ההקלדה (אחרת הקפשן מוכפל).
2. להדביק את הטקסט המלא של בלוק הוואטסאפ.
3. לצרף את הגרפיקה: `input[type=file]` מוזרק לעמוד, `file_upload` אליו, ואז
   `ClipboardEvent('paste')` עם `DataTransfer` שמחזיק את הקובץ, על שדה ההקלדה.
   **לא** ה-input של כפתור הצירוף בתחתית (`accept=image/*`) - הוא פותח את עורך הסטיקרים.
4. צילום מסך לאימות, ו**שליחה רק באישור מפורש.**
