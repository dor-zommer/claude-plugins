# osint-visualize - מנתונים לגרף

הופך תוצאת שאילתה מ-osint-db לגרף שאפשר להסתכל בו, ואז לייצא. **שני מצבי פלט, לא שלושה:**

1. **וידג'ט בצ'אט** — ברירת המחדל. גרף אינטראקטיבי לחקירה מהירה תוך כדי עבודה.
2. **ייצוא** — קוד הטמעה (HTML עצמאי) או קובץ תמונה (PNG). רק כשדור מבקש.

**זה לא `hamakom-data-page`.** שם בונים עמוד סקרולי-טלינג מלא לאתר — פרויקט גדול. כאן הגרף הוא כלי עבודה של הדסק.

## חוק ראשון: המספר קודם לגרף

**אף גרף לא נבנה בלי שאילתה שרצה.** אין נתוני דוגמה, אין הערכות, אין "בערך". אם השאילתה נקטעה — תקן אותה, אל תמציא מספר כדי שהגרף ייראה שלם.

**כל גרף חייב לשאת:** `N=` מספר הרשומות · טווח התאריכים · שם הטבלה · ומה סוננו החוצה. בלי אלה הגרף מטעה גם כשהוא מדויק.

**חוק הזהב של db-map חל** — אין אגרגציה בלי `WHERE`. ראה `references/db-map.md`.

## בחירת סוג הגרף לפי צורת הנתונים

| צורה | טבלאות אופייניות | גרף | מתי לא |
|---|---|---|---|
| דירוג — מי הכי הרבה | `exemptions`, `budget_contracts`, `budget_supports`, `mevaker_donations`, `mod_tenders` | **ברים אופקיים**, ממוין, 8-15 שורות | מעל 20 קטגוריות — עבור לטבלה |
| הרכב — מה מתוך מה | פילוח משרדים, סוגי בחירות | **treemap** או ברים מוערמים | פחות מ-4 חלקים — טבלה עדיפה |
| זמן | `news_headlines`, `police_announcements`, `idf_spokesman`, `decisions`, `legislation`, כל `publication_date` | **קו** לרציף, **עמודות** לבדיד | פחות מ-6 נקודות |
| התפלגות | סכומי תרומות, גדלי פטורים | **היסטוגרמה** | |
| גיאוגרפיה | `mavat_plans` + `yosh_plans` (יש lat/lng), `wp_article_locations`, `donor_city`, `election_city` | **מפת נקודות**, או **כורופלת** לפי מחוז | פחות מ-10 נקודות — רשימה |
| זרימה בין שני צדדים | תורם→מקבל, ספק→מפרסם, יוזם→חוק | **סנקי** | מעל 30 קשרים — הופך לספגטי |
| רשת קשרים | תיק ישות מצולב | **גרף קשרים** | תמיד לוודא שהצפיפות קריאה |
| פרלמנט | `knesset_votes` + `knesset_vote_options` | **ברים מקובצים** לפי סיעה, או רשת ח"כים | ⚠️ `faction_name` ריק בכנסת 25 — ראה db-map |
| השוואת סיקור | `news_headlines` לפי `outlet` / `sector` | **small multiples** | |

**כשבספק — טבלה.** גרף שלא מוסיף מעל טבלה הוא רעש.

## פלטת המותג

מקור-האמת הוא `plugins/hamakom-visuals/design-system/HAMAKOM-DS-2026.md`. **קובץ בפלאגין אחר לא נפתר בזמן ריצה, ולכן הטוקנים שבשימוש כאן משוכפלים במכוון — אם המותג משתנה, עדכן שם קודם וכאן אחריו.**

| תפקיד | ערך |
|---|---|
| רקע (שנהב) | `#faf9f5` |
| טקסט ראשי (דיו) | `#141413` |
| טקסט משני | `#3b3a36` |
| טקסט שלישוני, מקור, credit | `#6b6a63` |
| קווי רשת / קו-שיער | `#e3e1d8` |
| **מספר-נתון בולט, הדגשה** | טרקוטה `#D97757` |
| **ברים, סדרה ראשית** | מרווה `#788C5D` |
| **סדרה שנייה** | אברש `#8E6FA8` |
| סדרה שלישית | טרקוטה עמוק `#9C4527` |

**הכלל מה-DS:** מספר ענק בודד = **טרקוטה**. ברים = **מרווה**. סדרה שנייה = **אברש**. הצבע נדיר ולכן הוא קורא — אל תצבע כל בר בצבע אחר.

טיפוגרפיה בגרף: `Graphik HLAR` לתוויות ומספרים; אם לא זמין — `Arial` / `Helvetica`. כותרת גרף ב-`Publico Headline` אם זמין.

## עברית ו-RTL

- `dir="rtl"` על המכל, ותוויות ציר מיושרות לימין.
- **ברים אופקיים: הציר מימין לשמאל.** בר ארוך יותר מתקדם שמאלה.
- מספרים נשארים LTR בתוך טקסט עברי — עטוף בכיוון מפורש כדי שסכומים לא יתהפכו.
- קיצורים: `₪` אחרי המספר. אלפים `1,234`. מיליונים — "2.4 מ׳ ₪", לא `2400000`.
- תאריכים בעברית: `12.7.2026`, לא ISO.

## הרצף

### 1. הבנת השאלה
מה הגרף אמור להראות במשפט אחד. אם אי אפשר לנסח — עוד אין גרף.

### 2. השאילתה
הרץ מול osint-db לפי חוקי `db-map.md`. שמור את ה-SQL — הוא נכנס לכיתוב.

### 3. ניקוי
- אחד וריאנטים של שמות (ראה מלכודת סדר-השם ב-`mevaker_donations`)
- נרמל ישויות HTML (`&quot;`)
- הפרד `NULL` מאפס — הם לא אותו דבר, ואסור לצייר אותם יחד
- הסר כפילויות ידועות, **וציין בכיתוב שהוסרו**

### 4. וידג'ט בצ'אט
בנה גרף אינטראקטיבי ב-HTML/SVG עם הפלטה למעלה. Chart.js מותר; אחרת SVG ידני. הצג ישירות בשיחה.

### 5. ייצוא — רק לפי בקשה

**קוד הטמעה:** HTML עצמאי אחד, כל ה-CSS וה-JS inline, בלי תלות חיצונית פרט לספריות מותרות. רספונסיבי, `dir="rtl"`, ועובד בתוך iframe. שמור לתיקיית העבודה והצג את הנתיב.

**תמונה:** רנדר ל-PNG (headless chrome על ה-HTML, או matplotlib). רוחב 1200 לאתר, 1080 לרשתות. רקע שנהב אטום — לא שקוף. **ודא שהעברית לא נשברת** לפני שמוסרים.

### 6. בדיקה עצמית לפני מסירה
- המספרים בגרף תואמים לפלט השאילתה?
- הצירים מתחילים באפס? (בר שלא מתחיל באפס מטעה)
- יש `N`, טווח תאריכים ומקור?
- קריא בשחור-לבן?
- העברית תקינה ולא הפוכה?

## כיתוב חובה מתחת לכל גרף

```
מקור: osint-db · <שם הטבלה> · N=<מספר> · <טווח תאריכים>
<מה סוננו / אוחדו>
```

## מלכודות

- **סכום מול מבוצע.** ב-`budget_contracts` יש `volume` (היקף) ו-`executed` (בוצע). גרף שמערבב אותם שקרי. אותו דבר ב-`budget_supports`: `amount_approved` מול `amount_paid`.
- **טווחי זמן חלקיים.** שנה שנקטעת באמצע נראית כמו צניחה. סמן במפורש או חתוך.
- **`NULL` מצויר כאפס** — טעות נפוצה ומטעה.
- **גרף בלי מכנה.** "מי קיבל הכי הרבה" בלי לומר מתוך כמה — חסר הקשר.
- **סקרייפר שהפסיק לרוץ** נראה בגרף זמן כמו ירידה אמיתית. בדוק את מצב הסקרייפרים ב-`db-map.md` לפני שמציירים סדרת זמן.

כתוב בעברית, בלי אימוג'ים. הגרף הוא ראיה, לא קישוט — אם הוא לא מוסיף מעל טבלה, אל תבנה אותו.
