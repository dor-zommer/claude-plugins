# osint-candidate-funding - מי מימן את המועמד

בונה פרופיל מימון של מקבל תרומות מתוך `mevaker_donations`.

**כל מפרט הטבלה נמצא ב-`references/db-map.md`, סעיף `mevaker_donations`. קרא אותו לפני השאילתה הראשונה ואל תשכפל ממנו מספרים לכאן.**

## המלכודת המבנית שחייבים להכיר

**`election_date` ו-`election_period_name` ריקים בפריימריז.** אי אפשר לשייך תרומה למערכת בחירות דרכם. **יש לגזור את הקמפיין מאשכולות `publication_date`** - ולהציג את המיפוי במפורש בפלט.

וזכור: **תרומות ממשיכות להתפרסם חודשים אחרי הבחירות.** תרומה מאוחרת אינה בהכרח שייכת לקמפיין הבא - היא יכולה להיות דיווח מאוחר או כיסוי גירעון. בדוק `is_deficit_coverage`.

## הרצף

### 1. איתור המקבל

```sql
SELECT recipient, COUNT(*) n, ROUND(SUM(sum)) total
FROM mevaker_donations
WHERE recipient LIKE '%<שם>%'
GROUP BY recipient ORDER BY total DESC
```

LIKE רחב יאסוף אנשים אחרים ("ביטן" מחזיר גם "אביטן"). הצג את הווריאנטים והכרע לפני שממשיכים.

### 2. שליפה מלאה

```sql
SELECT donor_name, donor_city, donor_country, sum, publication_date,
       election_type, publication_type, is_deficit_coverage
FROM mevaker_donations
WHERE recipient = '<שם מדויק>'
ORDER BY publication_date
```

### 3. פילוח לקמפיינים

מיין לפי תאריך, זהה פערים של חודשים, קבע גבולות אשכול, **ואמת כל אשכול מול לוח הבחירות בפועל** - מתי נערכו הפריימריז ומתי הבחירות. אם אשכול נמשך מעבר למועד הבחירות, אמור זאת במפורש.

בדוק גם: האם למקבל יש רשומות ב-`election_type='local'` בנוסף ל-`primaries`? מועמד יכול לרוץ בשתי זירות.

### 4. ניתוח

- **חמשת התורמים הגדולים** ואיזה אחוז מהסך הם מהווים. מעל 50% = תלות
- **תורמים חוזרים** - מי תרם ביותר ממערכת אחת. אלה הקשרים העמידים
- **גיאוגרפיה** - כמה מהעיר של המועמד, כמה מבחוץ
- **חו"ל** - `donor_country NOT IN ('', 'ישראל')`
- **מימון עצמי** - המועמד מופיע כתורם לעצמו. שורה נפרדת בדוח
- **הלוואות וערבויות** בנפרד

### 5. הצלבה

לכל תורם משמעותי - `osint-donor-profile` (למי עוד תרם) ו-`osint-donations-crossref` (מה קיבל מהמדינה). הצלב מול `wp_articles` ו-`knesset_mk_individuals`.

**מה לאמת לפני פרסום:** שיוך כל אשכול למערכת הבחירות הנכונה מול לוח הבחירות; הפרסום המקורי אצל מבקר המדינה; ותגובת המקבל.

כתוב בעברית, בלי אימוג'ים, חד וקצר. תרומה חוקית ומדווחת אינה עבירה - הסיפור הוא בדפוס, בריכוזיות, ובמה שהתורם צריך.
