# הניוזלטר השבועי של "המקום הכי חם בגיהנום"

מטרה: להפיק כל שבוע **טיוטת ניוזלטר HTML מוכנה**, שדור צריך רק (1) לכתוב בה את פתיח
העורך, ו-(2) להפיל את תמונת השבוע מפלאש90 — וזהו, מדביק ל-Brevo ושולח.

הבסיס הוא הגיליון שפורסם ב-13.6.2026 ("קודם כל, שקרנים"). העיצוב משוחזר מילה במילה.

---

## כלל בטיחות (הכי חשוב — הלקח מהמשבר)

שני סשנים פעם דרסו זה את העבודה של זה כי ערכו את אותו קובץ. לכן:

- **לעולם לא עורכים קובץ ניוזלטר קיים.** `build_weekly.py` תמיד כותב קובץ **חדש**
  עם חותמת תאריך-שעה (`weekly_YYYYMMDD_HHMMSS.html`).
- כל הרצה שבועית יושבת בתת-תיקייה עם תאריך משלה (`issues/YYYY-MM-DD/`).
- אם צריך לתקן — בונים מחדש מ-`issue.json`, לא מערבבים ידיים בקובץ הפלט.

---

## הפינות הקבועות (לפי הסדר)

1. **כותרת** — שחור, לוגו, "הניוזלטר השבועי · {תאריך}"
2. **פתיח עורך** — `<<< דור ממלא >>>` (placeholder מודגש בצהוב עד שממלאים)
3. **חדש באתר / פרויקט מתעדכן** — אופציונלי
4. **תחקיר השבוע** — כתבה מובילה, תמונה גדולה + כותרת + תקציר + קרדיט
5. **הנתון של השבוע** — אופציונלי, גרף/אינפוגרפיקה
6. **בעקבות הפרסום** — אופציונלי, באנר צהוב + כתבת המשך
7. **עוד שברים שקרו השבוע** — רשימת כתבות (תמונה + כותרת + תקציר + קרדיט)
8. **תמונת השבוע** — פלאש90, באמצע הרשימה. תמיד מופיעה; אם אין תמונה → תיבת placeholder
9. **מתחת לרדאר** — אופציונלי, כתבה מודגשת
10. **ברשתות שלנו** — אופציונלי, ריל/פוסט
11. **ציטוט השבוע** — ציטוט חזק מתוך אחת הכתבות
12. **דעות וטורים** — טור מוביל + רשימת טורים
13. **המלצות קריאה** — אופציונלי, משותפות העיתונות העצמאית
14. **קרן ההגנה המשפטית** — בלוק קבוע (תמיכה בקרן SLAPP)
15. **באנר שקוף + פוטר** — רשתות, תמיכה, הסרה

עיצוב — **HaMakom DS 2026** (מקור-אמת: `plugins/hamakom-visuals/design-system/HAMAKOM-DS-2026.md`):
רוחב 600px · RTL · כרטיס שנהב `#faf9f5` על מסגרת `#e6e3da` · דיו `#141413` · טרקוטה `#D97757`.
פס-חתימה טריקולור (טרקוטה·מרווה·אברש) בראש הגיליון. פונטים: **Suez One** לכותרות/תצוגה,
**IBM Plex Sans Hebrew** לגוף/UI (עם Heebo כ-fallback — מיילים מפילים web-fonts).
הקבועים ב-`build_weekly.py`: `INK`/`IVORY`/`TERRA` + `GOLD` (טרקוטה כהה לטקסט אקסנט) /
`AMBER` (טרקוטה מובהרת ללייבלים/כפתורים על דיו) · `FONT_HEAD`/`FONT_BODY`.

## זרימת העבודה

הקבצים: `scripts/fetch_week.py`, `scripts/build_weekly.py`, `scripts/issue.example.json`.

### 1. משיכת הכתבות
```bash
cd <תיקיית-הפרויקט>
mkdir -p issues/$(date +%F) && cd issues/$(date +%F)
DAYS=7 OUT_DIR=. python3 <engine>/fetch_week.py
```
מייצר `articles.json` (כל כתבות השבוע) + `issue.draft.json` (שלד מוצע: lead = התחקיר
האחרון, rundown = השאר, opinions = קטגוריית "דעות"). אם יצאו מעט כתבות — להגדיל `DAYS`.

### 2. עריכת `issue.json` (לשמור בשם `issue.json`)
- **lead** — לוודא שזו הכתבה המובילה הנכונה (הכי חזקה, לא בהכרח האחרונה).
- **rundown** — לסדר לפי חשיבות; להסיר טורים (הם נכנסים ל-opinions).
- **photo_of_week** — להשאיר placeholder + לכתוב 2-3 הצעות חיפוש לפלאש90 בהתאם לסיפור
  הדומיננטי של השבוע, ולמלא קרדיט "צילום: ___ / פלאש 90". כשדור ליד המחשב — אפשר
  לגלוש לפלאש90 בדפדפן שלו (מחובר) דרך תוסף Claude, לבחור 3-4 מועמדות ולהוריד.
- **quote** — למשוך משפט חזק מאחת הכתבות + לציין מי אמר.
- אופציונלי: `project`, `data_stat`, `followup`, `hero`, `reel`, `reads`.
- **editor_note** — להשאיר `<<< >>>` כדי שדור יכתוב. (זה הדבר היחיד שחובה עליו.)
- `legal` ו-`support_banner`: להשאיר `"default"`.

ראה `issue.example.json` לדוגמה מלאה עם כל הפינות.

### 3. בנייה
```bash
ISSUE=issue.json ARTICLES=articles.json OUT_DIR=. python3 <engine>/build_weekly.py
```
מדפיס נתיב הקובץ, איזון תגיות, ושורת **"TO FILL"** עם מה שנשאר למלא.

### 4. מסירה
להציג את הקובץ לדור (present_files) + לפרט מה ב-"TO FILL". דור פותח בדפדפן, ממלא פתיח
+ תמונה, ומדביק ל-Brevo.

## טיפול בתמונת השבוע (פלאש90)

- בהרצה האוטומטית (שישי בבוקר, בלי דור): תמיד **placeholder** + הצעות חיפוש + פורמט קרדיט.
  לא שומרים סיסמאות ולא מפעילים דפדפן בלי דור.
- בהרצה ידנית כשדור ליד: לגלוש לפלאש90 בדפדפן שלו (כשהוא מחובר) דרך תוסף Claude,
  להציע 3-4 ולהוריד את הנבחרת. את ה-URL/הקובץ שמים ב-`photo_of_week.img`.

## מקור הקרדיט (חשוב)
שם הכותב נמשך מ-`yoast_head_json.author` — לא משדה ה-author הרגיל של וורדפרס
(שמחזיר משתמש מערכת). זה כבר מטופל ב-`fetch_week.py`.
